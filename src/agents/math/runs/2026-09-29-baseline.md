## What the failures actually are

The headline 14/26 mixes agent faults with scoring faults. Read by cause:

- **Missing exam-format knowledge: 5 cases, the main finding.** The runtime corpus holds learning outcomes but no assessment format: no AO weightings, paper structure, per-paper calculator rules or MF27 contents. With nothing to retrieve, the agent sometimes filled the gap confidently and wrongly, telling a student A-Math Paper 1 is non-calculator and that they must know an expansion MF27 supplies. That breaks the prompt's own rule to say plainly when evidence is missing.
- **A runaway graph: 1 case, scored as a pass.** On `1/x` the agent called the graph tool and then also drew its own base64 SVG until it hit the output limit. The reply was cut off before the image markup closed, so the guardrail, which only strips complete image links, let it through. The case still scored 100% because its checks require only '0' and the tool name.
- **Verification skipped on word problems: 4 cases.** Answers correct, but no tool call. The first-step rule fires on a verb like 'solve' or on numbers joined by an operator; '23 sweets, give 8 away' has neither, and the model then skips the check the prompt asks for. Word problems are where most AO2 marks sit.
- **Scoring faults: 2 cases.** `\frac{1}{2}` failed a literal '1/2'; 'Pythagorean theorem' failed 'pythagoras'.
- **Outdated case: 1.** `math-topology-refuse` expects refusal; the agent labelled the scope and helped, which is the agreed policy.

The mathematics was right in every case examined. The problems are knowledge of the examination, one generation fault, and verification discipline.

## Limits of this run

- One run; no variance measured.
- Gold answers had not yet been checked against the primary documents. The source-checked corrections are recorded in `2026-09-29-run4.md`.
- Tool evidence is names only, deduplicated: the runner cannot show mode, arguments, repeated calls, or whether a result was used.
- Several phrase checks cannot fail meaningfully, as the passing graph case shows.
- Cases call the Math agent directly, bypassing routing; live questions about the syllabus currently route to Desk.
- Latency is noisy: some cases took 85–115 s with few tokens, which points at queueing rather than the agent.

## Actions this run implies

1. Guardrail: also strip unclosed image markup and bare base64 image data; add a truncated-input test.
2. Prompt: the graph tool draws the picture; never write images, SVG or base64.
3. Bound output length on the Math agent so a runaway cannot cost 40% of a run.
4. Exam-format facts: put the reviewed assessment-format sections where retrieval can reach them, agreeing the location with the corpus owner.
5. First-step rule: decide whether word problems with numbers should start from the solver.
6. Scoring: equivalence-based answer checking; rewrite `math-topology-refuse`; accept 'Pythagoras' theorem' or 'Pythagorean'.
